# Language support matrix

Generated by `crates/ingest/tests/language_matrix.rs` — do not edit by hand; the test
rewrites this file from code truth and fails only when the truth sources are broken.

The four columns are **separate claims** (IMPROVEMENTS #10): a compiled parser does not
imply outline rules; outline rules do not imply call/import extraction; extraction does
not imply measured resolution precision. Precision is *labelled-gated* only where
`crates/index/tests/resolution_eval.rs` carries an exhaustively labelled fixture whose
precision and recall must both be 1.0.

harness; `extracted; not fixture-gated` means edges exist with honest grades but no
exhaustive per-language label set yet.
